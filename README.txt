DUST DEVIL’S MC — VERSION WEB AVEC SYNCHRONISATION AUTOMATIQUE

1. Créer un dépôt GitHub et y envoyer les fichiers de ce dossier (index.html, netlify.toml, netlify/functions/actions.js).
2. Dans Netlify : Add new project > Import an existing project > GitHub, choisir le dépôt et déployer.
3. Ouvrir l’adresse https://...netlify.app et la rubrique Actions & salaires.
4. Cliquer « Actualiser les actions ». Le journal essaiera ensuite de s’actualiser toutes les 60 secondes.

IMPORTANT :
- Le Google Sheets source doit autoriser la lecture publique de l’onglet Formulaire Actions. Sans cela, le relais renverra une erreur.
- Un lecteur ayant accès au site peut techniquement lire les déclarations récupérées par le relais. Ne pas y mettre de données privées.
- Les rôles de la tablette sont une simulation locale, pas une sécurité réelle.
- Les données saisies dans la tablette sont enregistrées dans le navigateur de chaque utilisateur, PAS synchronisées entre utilisateurs ni envoyées au Google Sheets.
- L’ancien aperçu Google Sheets des quotas reste en haut.
- Les 133 actions du dernier Excel sont préchargées comme secours.
- Ce paquet n’est PAS encore hébergé : le propriétaire doit effectuer le déploiement Netlify.
